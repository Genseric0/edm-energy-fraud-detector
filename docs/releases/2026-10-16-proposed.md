# Mudança de password e isolamento da demonstração

Proposta no [PR #8](https://github.com/Genseric0/edm-energy-fraud-detector/pull/8),
dependente do PR #7; ainda sem versão publicada ou integração em main.

- Novo botão «Alterar password» para a própria conta. Exige a password actual,
  confirma a nova e termina as sessões existentes mediante incremento de versão.
- BCrypt, versão de autenticação e evento mínimo de auditoria são guardados numa
  transacção. Falhas não deixam uma mudança parcial. Protecção contra mudanças concorrentes.
- Os dados sintéticos deixam de ser carregados automaticamente. Para demonstração,
  activar explicitamente `EDM_SEED_ENABLED=true` numa base isolada; simulações continuam
  a exigir adicionalmente o perfil `demo`.
- Migração aditiva V4 para eventos de password. Não altera passwords existentes.
  Variáveis do primeiro arranque continuam sem substituir contas persistidas.
- Tour PT/EN com capturas reais actualizadas e revisão documentada dos riscos de dados.

Estas alterações não concluem a Fase 0 nem certificam uso com dados reais. Resultados
de testes e origem das imagens estão no PR e no registo de progresso. Não foram alterados
segredos externos, histórico Git, base do utilizador ou configurações de produção.

## English

Proposed in PR #8, pending human review. Users can change their own password after
confirming the current one. The BCrypt hash, account token version and minimal audit
event commit atomically; previous tokens no longer authenticate subsequent requests.
Synthetic grid seeding now requires explicit opt-in. V4 is additive and preserves
existing credentials. This is not a production release or completion of the roadmap.
